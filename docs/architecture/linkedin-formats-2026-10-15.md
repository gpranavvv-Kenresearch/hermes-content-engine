# Shared LinkedIn/Facebook formats and concise prompts

Reviewed 15 October 2026. These are editorial patterns to test, not evidence of guaranteed LinkedIn reach or search rankings. Repository examples never authorize invented experience, quotes, market figures or country claims.

The user approved all ten samples on 15 October 2026 and specified one shared format pool for LinkedIn and Facebook. These ten are frozen. Further additions or structural changes require sample review and explicit user approval. This rule is also recorded in the project `AGENTS.md`.

## Implemented formats

| ID | Body | Evidence requirement |
| --- | --- | --- |
| insight-brief | Statement hook → market snapshot → three distinct bullets → implication | Three different supported observations |
| short-narrative | Situation → evidence → tension → implication, in natural paragraphs | A supported tension; no invented personal story |
| evidence-to-decision | Business decision → two supported options → trade-off → decision criterion | Implications explicitly separated from findings |
| country-contrast | Hook → snapshot → three country perspectives → implication | Notes must name at least three countries; each distinction must be supported |
| stat-spotlight | One statistic → source and context → nuance → implication | At least one verified fact |
| forecast-timeline | Hook → baseline → forecast → supported shift → implication | Comparable verified values with years, units, market and geography |
| two-lens-comparison | One insight → two labelled analytical lenses → shared implication | Two distinct supported perspectives |
| source-quote-analysis | Exact excerpt → attribution → context → implication | A supplied primary-source note; opening excerpt is validated |
| evaluation-checklist | Evaluation task → three screening bullets → decision implication | Three evidence-backed considerations |
| market-watchlist | Outlook → three Watch-labelled paragraphs → implication | Three supported signals, with qualified forecast language |

All end with a neutral report link, one discussion question, and topical hashtags. A regional statement stays regional. Explicit source groupings such as Japan and South Korea may stay grouped. Mentioning countries alone does not prove a comparison; the writer and supervisor still need the actual supporting notes.

## Short writing contract

> Share one evidence-backed industry insight. Open with the selected concise statement, statistic or source quote; introduce the market and keyword naturally. Use the selected format only. State headline figures once. Make every paragraph add a distinct observation. Preserve scope, dates and forecast wording; attribute findings to Ken Research. Use plain language and short natural paragraphs. Bold every Ken Research mention; keep other text plain with at most one optional short figure emphasis. End with the report link and one specific discussion question. Do not invent country detail or experience.

The prompt includes only one selected format, not this entire catalogue. Old five-point style examples and overlapping technique lists are omitted for both platforms. The supervisor uses a concise fixed checklist. Numeric, source, keyword and hard-length checks remain enforced. Narrative layouts do not trigger mandatory-list repairs. Validator rewrites receive the same selected format, question count and prior corrections.

Targets: 1,000–1,700 characters; hard cap 2,280. The source evidence block remains complete so concision never hides supporting notes from the supervisor.
